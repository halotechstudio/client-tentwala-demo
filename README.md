# Tentwala: live demo

A working simulation of **Tentwala**, a booking marketplace for tent houses in Rajasthan. It shows all three apps side by side, sharing one live state:

- **Customer app**: plan a function, get a smart estimate by guest count, pay an advance into escrow, share the delivery OTP, confirm the return count, rate the vendor.
- **Vendor app**: register with KYC, accept bookings (stock is blocked by date), dispatch, collect the OTP, record the return count, get paid next morning.
- **Admin dashboard**: approve vendors, watch every booking, see the escrow ledger, release payouts, resolve disputes, set commission and fees.

**Open the demo:** https://halotechstudio.github.io/client-tentwala-demo/
**Product manual (PDF):** [Tentwala-Product-Manual.pdf](Tentwala-Product-Manual.pdf)

## Using it

Press **Auto-play** to watch the whole journey, or **Next step** to go one step at a time. Every button inside the apps also works by hand. **Reset** starts over.

Add `?step=N` to the link to open with N steps already done. For example, `?step=7` opens at the delivery OTP.

Everything runs in the browser. No data leaves the page, and payments, escrow and messages are simulated.
